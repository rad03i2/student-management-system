# Contributing

Thanks for contributing to Student Management System.

1. Use JDK 17+ and Maven 3.9+.
2. Keep the core dependency-free unless a dependency has a clear maintenance benefit.
3. Add or update tests for behavior changes.
4. Run `mvn clean package` and the integration harness before submitting a pull request.
5. Keep commits focused and never commit real student records, credentials, generated `target/`, or local `data/`.

Bug reports should include the command, expected behavior, actual behavior, Java version, and OS. Security reports should follow `SECURITY.md` rather than public issues.

By contributing, you agree that your contribution is licensed under the repository's MIT License.
