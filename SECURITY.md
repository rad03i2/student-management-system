# Security Policy

## Supported version
Security fixes target the latest version on `main`.

## Reporting
Please report suspected vulnerabilities privately through GitHub's security reporting features when available. Do not publish real student records, credentials, or other personal data in an issue.

## Data and trust model
The application is a local single-user CLI. It does not authenticate users, encrypt the data directory, contact external services, or claim protection against a malicious local user. Protect filesystem permissions and backups according to the sensitivity of your records.
